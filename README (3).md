# Blocksmith Pixel Art

Turn any image into Minecraft block pixel art - runs 100% in your browser.

- Block map with codes, zoom, grid, click-to-highlight a block type
- **Row-by-row / column-by-column build guide** with run-length lists ("5x White Wool (3-7)")
- Pick exactly which blocks to use (wool, concrete, terracotta, planks, stone, ...), skip expensive or falling blocks, limit the number of block types
- Brightness / contrast / saturation, optional dithering (Floyd-Steinberg), transparent pixels become air
- Material list with stacks and shulker boxes
- **Download:** `.schem` (WorldEdit / FAWE), `.litematic` (Litematica), structure `.nbt`, map PNG, material CSV, build guide `.txt`

Wall: stand south of it and look north to read the picture. Floor: top of the picture points north.
Files are written for Minecraft 1.20.1 data and upgraded automatically by newer versions.
